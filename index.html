01 · Direction of travel

Cascade chỉ chảy
theo một hướng.

Mỗi tầng chỉ nên phụ thuộc vào các quyết định tổng quát nằm phía trên. Điều này ngăn generic rule vô tình thắng component cụ thể.

↘

Reach

Rộng → Hẹp

Reset ảnh hưởng toàn trang; utility chỉ xử lý một trường hợp.

* → .u-hidden
↗

Explicitness

Chung → Cụ thể

Element mô tả HTML; component và utility nói rõ ý định UI.

button → .c-button
≋

Specificity

Thấp → Có kiểm soát

Source order hỗ trợ override mà không tạo cuộc đua selector.

0,0,1 → 0,1,0

02 · Layer map

Bảy tầng.
Bảy trách nhiệm.

Namespace và vị trí file cho biết một rule thuộc tầng nào trước khi bạn cần mở stylesheet.

  1. 01
    Settings --token

    Màu, spacing, font và các quyết định cấu hình.

    --color-accent
  2. 02
    Tools @mixin

    Mixin và function không phát sinh CSS trực tiếp.

    fluid-type()
  3. 03
    Generic *

    Reset, normalize và box-sizing toàn cục.

    *::before
  4. 04
    Elements tag

    Kiểu mặc định cho HTML element không có class.

    h1, a
  5. 05
    Objects o-

    Pattern layout cấu trúc, không mang skin.

    .o-grid
  6. 06
    Components c-

    UI cụ thể, dễ nhận diện và tái sử dụng.

    .c-card
  7. 07
    Utilities u-

    Helper đơn nhiệm, override có chủ đích.

    .u-full-width
