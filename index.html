03 · Theme category

Module không đổi.
Identity thay thế.

Theme chỉ cung cấp token. Module đọc các token đó nên không cần sao chép hay override từng selector.

.theme-violet
V

Module dùng theme tokens.

.theme-forest
F

Cùng HTML, theme khác.

.theme-sunset
S

Không đổi module CSS.

main.css

/* Category order: general → specific */
@import "base/base.css";
@import "layout/layout.css";
@import "modules/dashboard.css";
@import "state/state.css";
@import "theme/theme.css";
