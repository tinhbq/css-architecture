03 Architecture

Mỗi layer có một trách nhiệm

Độ ưu tiên tăng dần từ trên xuống dưới.

  1. reset

    Xóa khác biệt mặc định không mong muốn giữa các trình duyệt.

  2. tokens

    Lưu các quyết định thiết kế dùng chung dưới dạng custom properties.

  3. base

    Đặt style mặc định cho body, heading, link và các element khác.

  4. layout

    Quản lý luồng trang, container, grid và khoảng cách vùng.

  5. components

    Định nghĩa các khối giao diện độc lập và tái sử dụng được.

  6. utilities

    Cung cấp class đơn nhiệm để điều chỉnh nhanh một thuộc tính.

  7. overrides

    Xử lý ngoại lệ có phạm vi rõ ràng và được ghi chú.

Cascade layer

Utility thắng component

Component đặt border màu tím, nhưng utility .u-border-accent đổi nó sang màu cam vì layer utilities có ưu tiên cao hơn.

main.css

/* Low-priority layer */
@layer components {
  .playground .notice-card {
    border-color: var(--color-primary);
  }
}

/* Higher-priority layer */
@layer utilities {
  .u-border-accent {
    border-color: var(--color-accent);
  }
}

CSS is a language of constraints, not a collection of patches.
